# Void Core

**Category:** Technology

Void Core is a moon-sized Dominion battle station built around a reactor and an energy weapon capable of destroying an inhabited planet. This article belongs to the fictional Astraforge knowledge base and is self-contained so that the entity can be understood without relying on an external fictional universe.

The first station is destroyed during the Battle of Helios Gate. N7-KO carries engineering plans showing that a small external thermal channel connects indirectly to the main reactor. Lio Arken exploits this weakness during the Coalition attack.

A second Void Core is later constructed near the Verdant Moon. It includes design changes and is protected by an external shield generator. The Coalition attacks before construction is complete and uses the exposed internal structure as an opportunity.
