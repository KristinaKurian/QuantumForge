# N7-KO

**Category:** Automaton

N7-KO is a compact navigation and maintenance automaton that carries technical data in protected internal storage. This article belongs to the fictional Astraforge knowledge base and is self-contained so that the entity can be understood without relying on an external fictional universe.

N7-KO stores the stolen engineering plans that reveal the critical vulnerability of the first Void Core. Because the complete data package cannot be transmitted safely, several groups attempt to capture the automaton physically.

N7-KO works closely with PR-3X but is much more willing to take risks. It can interface with ship computers, security doors, navigation systems, and maintenance terminals, making it useful far beyond its original technical role.
