# Task 2 — Подготовка базы знаний

## Предметная область

В качестве исходной структуры выбрана вселенная **Star Wars**. Чтобы не хранить большие фрагменты чужих статей, база содержит краткие перефразированные описания сущностей и связей, после чего все ключевые персонажи, планеты, организации, технологии и события заменены вымышленными названиями.

Финальный локальный мир называется **Astraforge**.

## Результат

- `knowledge_base/` — **38 Markdown-документов**, один файл — одна сущность;
- `terms_map.json` — словарь `исходный термин -> вымышленный термин`;
- `source_pages.json` — список исходных сущностей/reference URL;
- `prepare_knowledge_base.py` — пример автоматической очистки и подмены терминов;
- `validate_kb.py` — проверка базы.

`terms_map.json` не должен попадать в векторный индекс: иначе RAG увидит связь между вымышленными и исходными именами.

## Логика подготовки

1. Выбрать ключевые сущности исходного мира.
2. Получить чистый текст без HTML, меню, навигации и сносок.
3. Перефразировать описание, сохранив факты и связи.
4. Применить замены от самых длинных терминов к коротким.
5. Сохранить одну сущность в одном документе.
6. Проверить, что исходные термины не остались в `knowledge_base/`.

## Проверка

```bash
python Task2/validate_kb.py
```

Ожидаемый результат:

```text
OK: 38 documents
OK: no mapped source terms found in knowledge_base
```
