# Task 2 — Подготовка базы знаний

Для учебной базы использована структура вселенной Star Wars, но тексты перефразированы, а ключевые сущности заменены вымышленными названиями. 

Итоговый мир называется **Astraforge**.

## Результат

| Артефакт | Назначение |
|---|---|
| `knowledge_base/` | 38 основных Markdown-документов, одна сущность на файл + для Task 5 добавляется `malicious_injection.md` = всего 39 документов |
| `terms_map.json` | исходный термин → вымышленный термин |
| `source_pages.json` | список исходных сущностей/reference URLs |
| `prepare_knowledge_base.py` | пример очистки и подмены терминов |
| `validate_kb.py` | проверка количества файлов и отсутствия исходных терминов |

`terms_map.json` не индексируется, чтобы RAG не видел соответствия между исходными и вымышленными названиями.

## Проверка

```bash
python Task2/validate_kb.py
```
